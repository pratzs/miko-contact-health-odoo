# Miko Contact Health for Odoo

Finds email addresses that cannot receive mail, contacts sharing one mailbox, and
the fields an invoice cannot be issued without. Validated entirely offline: no DNS,
no test messages, no third party service.

Published on the Odoo Apps Store by Tripster Developers.

contain Python.
